# Security Policy

## Supported versions

These versions are actively maintained and supported:

| Version   | Supported          |
|-----------|--------------------|
| `1.1.x`   | ✅                 |

If you're on an unsupported version, upgrade to the latest release.

## Reporting a vulnerability

If you discover a security vulnerability, **please do not create a public issue**.

Instead, follow these steps:

1. Email [dmitry@korotovsky.io](mailto:dmitry@korotovsky.io) directly.
2. Provide as much detail as possible, including:
   - Steps to reproduce the vulnerability
   - Affected versions
   - Potential impact
   - Any suggested remediation (if available)

## What to expect

- We will confirm we received your report.
- We will investigate and may reach out for more details.
- Once we confirm the issue and develop a fix, we will coordinate a release.

## Responsible disclosure

Please:
- Do not publicly disclose the vulnerability until we have released a fix.
- Give us adequate time to address the issue.

Thank you for helping keep this project and its users secure.
